# 🎨 InvoiceFlow: Brand Identity & Visual Design Brief

## 1. Brand Essence & Vision

**InvoiceFlow** bridges institutional finance and cutting-edge zero-knowledge cryptography. The visual language embodies the **Midnight "half-light, half-shadow" philosophy**: mysterious, obsidian dark backgrounds illuminated by vibrant cyber-cyan, neon emerald, and gold glows.

- **Tagline:** Zero-Knowledge Invoice Factoring Protocol.
- **Brand Attributes:** Confidential, Mathematical, Institutional-Grade, Sleek, Futuristic.

---

## 2. Color System & Design Tokens

| Token Name | Hex Value | Semantic Usage |
|:---|:---|:---|
| **Deep Space Background** | `#03050c` | Primary canvas background |
| **Obsidian Surface** | `#080d1a` | Card and modal surfaces |
| **Cyber Cyan** | `#06b6d4` | Primary brand accent, interactive buttons, highlights |
| **Nebula Purple** | `#a855f7` | Secondary accent, ZK circuit execution indicators |
| **Emerald Confirmed** | `#10b981` | Positive status, verified on-chain proofs, successful settlements |
| **Glowing Gold** | `#fbbf24` | Yield percentages, APY badges, financial values |
| **Slate Text (Muted)** | `#94a3b8` | Body descriptions, secondary labels |

---

## 3. Typography Hierarchy

- **Headings & Display:** `Space Grotesk`, `Outfit`, sans-serif (700 / 800 weight).
- **Body & Controls:** `Inter`, sans-serif (400 / 500 / 600 weight).
- **Cryptographic Hashes & Telemetry:** `Share Tech Mono`, `JetBrains Mono`, monospace.

---

## 4. Design Components & Micro-Interactions

- **Reputation Ring:** Circular SVG progress indicator displaying counterparty risk scores (0-100) with dynamic color gradients.
- **Circuit Stepper:** 4-step interactive timeline (`Committed` $\to$ `proveAccess` $\to$ `Tokenized` $\to$ `Settled`) with glowing pulse animations.
- **Glassmorphism Panels:** 1px subtle neon borders with backdrop-blur filters.
